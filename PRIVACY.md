# Privacy model

This repository is intentionally separated from any personal application and has **no user records**. It does not include real customer data, contact information, tokens, analytics, production configuration, email connections, private stock feeds or credentials. Products in `examples/` are placeholders. The checker makes outbound requests only when run without `--demo` against explicitly configured URLs.

Never submit actual purchase receipts, personal delivery addresses, private retailer communications or waitlist details in public issues. Review metadata, commit authors and Git history before publishing.
